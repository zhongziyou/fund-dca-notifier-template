# 基金定投日报（估值驱动）

每天 14:30（北京时间）自动抓取持仓基金净值和跟踪指数的估值，按**估值百分位**判断加仓/暂停/止盈，发到你的 QQ 邮箱。

## 核心策略：看估值，不看浮盈亏

加仓减仓的本质是"这东西现在贵不贵"，而不是"你相对自己的成本赚了还是亏了"（那会被你买在高点还是低点误导）。所以本工具**每天自动抓取每只基金跟踪指数的 PE 历史百分位**来定方向：

| 估值百分位 | 档位 | 建议动作 |
|---|---|---|
| < 20% | 深度低估 | 加倍定投 + 可一次性买入 |
| 20% ~ 30% | 低估 | 加倍定投 |
| 30% ~ 70% | 正常 | 正常定投，不动 |
| 70% ~ 80% | 偏高 | 暂停定投 |
| > 80% | 高估 | 暂停定投 + 分批止盈 |

- 处于「偏高/高估」时，**每天都会提醒暂停**，直到跌回正常档才自动停止。
- 估值档位发生**变化**（如 正常 → 偏高）时，报告会额外标注 ⚠️。

## 数据来源与时效（重要）

- **净值 / 日涨跌**：天天基金接口，是**上一交易日（T-1）**的数据。场外基金 T 日净值要当晚才公布，14:30 时拿不到当天净值——这是场外基金的固有特性。
- **估值（PE 历史百分位）**：蛋卷估值接口，同样是**最近已收盘交易日**的数据。
- 两者都是"慢变量"，对"暂停/加仓/止盈"这类低频决策**完全够用**。你要 15 点前下单，成交价本来就是当天收盘净值，下单时看不到、也无需看到。

## 使用步骤

### 1. 建私有仓库

```bash
cd fund-dca-notifier
git init && git add . && git commit -m "init"
git remote add origin <你的私有仓库地址>   # 建议 Private
git push -u origin main
```

### 2. 检查 config.json

已按你的持仓填好。字段说明：

- `funds[].code` / `name`：基金代码、名称（名称仅展示用）。
- `funds[].valuation_index`：**估值跟踪的指数代码**（蛋卷接口的 `index_code`），已配好：
  - 008114 红利低波 → `CSIH30269`（红利低波）
  - 007721 标普500 → `SP500`
  - 016453 纳指100 → `NDX`
  - 海外长钱（投顾）无估值指数，按正常定投处理。
- `cost_price` / `shares`：平均成本价、持有份额（算收益率/市值用，仅展示）。
- `per_period` / `dca_frequency`：每期定投金额、频率（仅展示）。
- `tranche_amount`：一次加仓的参考金额（低估时提示用）。

### 3. 海外长钱（雪球投顾）

它没有公开净值/估值接口，报告里是**快照数据**。每次你加仓后，手动更新 `config.json` 里的 `amount`（当前持有金额），或把最新金额告诉我帮你改。

### 4. 开通 QQ 邮箱 SMTP 并拿授权码

QQ 邮箱 → 设置 → 账户 → 开启「SMTP 服务」，短信验证后得到**授权码**（不是登录密码）。

### 5. 配置密钥

GitHub 仓库 → Settings → Secrets and variables → Actions → New repository secret：

- 名称 `SMTP_PASSWORD`，值为授权码。

### 6. 本地测试（可选）

```bash
pip install -r requirements.txt
SMTP_PASSWORD=你的授权码 python main.py   # 真实发邮件并写 state.json
python main.py                            # 只打印报告、不发邮件
```

### 7. 定时运行

已配好 GitHub Actions，每天北京时间 **14:30** 自动跑（`.github/workflows/daily.yml`），也可在 Actions 页手动「Run workflow」。

> ⚠️ GitHub Actions 定时任务可能有几分钟到半小时延迟，若担心赶不上 15:00，把 daily.yml 的 cron 从 `30 6 * * *` 改成 `20 6 * * *`（14:20）。

## 说明与限制

- 估值数据来自蛋卷公开接口，若某天接口失败，报告会标注「数据异常」，不影响下次运行。
- 美股指数（标普500/纳指）估值因时差天然滞后 1~2 天。
- 分红、手续费未计入；成本价由你给的持有收益率反推，仅供展示。
- 本工具只做数据展示和规则提示，**不构成投资建议**。
